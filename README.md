# Étude de marché et clustering — Python

Projet réalisé dans le cadre de ma **certification Data Analyst**.

## Présentation

Ce projet consiste à exploiter des données dans le cadre d’une étude de marché afin d’identifier des groupes présentant des caractéristiques similaires.

L’objectif est de transformer plusieurs variables en informations exploitables pour aider à orienter une décision métier et identifier des marchés ou profils présentant un intérêt particulier.

## Démarche

Le projet comprend plusieurs étapes :

- exploration et préparation des données ;
- sélection et analyse des variables pertinentes ;
- analyse des relations entre les différentes variables ;
- standardisation des données lorsque nécessaire ;
- réalisation de segmentations ;
- comparaison de plusieurs méthodes de clustering ;
- interprétation des groupes obtenus ;
- sélection de groupes présentant un intérêt pour l’étude de marché.

## Méthodes utilisées

Deux approches principales de clustering sont utilisées :

- **classification ascendante hiérarchique (CAH)** ;
- **K-means**.

Ces méthodes permettent de regrouper les observations selon leurs caractéristiques et de faire ressortir différents profils.

## Compétences mises en œuvre

- Exploration et préparation de données
- Analyse statistique

- K-means
- Analyse et interprétation de groupes
- Traduction d’analyses statistiques en recommandations métier

## Visualisations

Le projet comprend notamment des visualisations permettant :

- d’explorer les relations entre les variables ;
- de comparer les résultats des différents clusterings ;
- d’analyser les groupes obtenus ;
- de faciliter l’interprétation des résultats.

Ce projet montre ma capacité à mener une analyse exploratoire, utiliser des méthodes de segmentation et interpréter les résultats dans le contexte d’une problématique métier.

Il illustre également ma capacité à passer d’un ensemble de données à une segmentation permettant d’appuyer une étude de marché.
